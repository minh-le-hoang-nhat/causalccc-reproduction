4. Comparaison avec la table S5

  • Comparaison par identifiants des partenaires, sans tenir compte de l'ordre (la table S5 écrit souvent IL7 receptor_IL7 là où notre base écrit IL7_IL7_receptor).
  • 706 paires dans la table S5 ; 342 existent dans notre base v5 ; 297 y sont significatives.
  • Les paires absentes viennent de l'ancienne version de CellPhoneDB (par exemple CXCL12_CXCR3, récepteurs ACKR).
  • Reproduction exacte impossible avec ce fichier : la table S5 couvre environ 53 types, dont certains absents du h5ad (NCC, Muscle_progenitors, Epi_PAX8, Fb_early, TEC_early).

Limites et suite

  • Le stade est très lié au type cellulaire : cTEC 96 % early, mTEC(I) 79 % late, endothélium 92 % late. Les comparaisons entre stades ne valent que pour quelques types.
  • Petits groupes : ETP 316 cellules, endothélium lymphatique 115.
  • Moitié des cellules en chimie 3', moitié en 5' : à inclure comme variable de contexte dans MIIC.
Étape suivante : CausalCCC, un axe à la fois. 1) FGF7:FGFR2, fibroblastes → TEC ; 2) RANKL, ILC3 → mTEC(II) ; 3) Notch, TEC → ETP ; 4) LTB:LTBR en dernier (signal diffus). Pour MIIC, toutes les cellules des types choisis, avec le stade et la chimie comme variables de contexte.
